# YL Studio storefront

Responsive fashion storefront built with semantic HTML, CSS and vanilla JavaScript.

## Run it

1. Extract the ZIP and open this folder in VS Code.
2. Open `index.html` in a browser. VS Code Live Server is optional.

## Included interactions

- Mobile navigation drawer
- Search and category filtering
- Product sorting
- Add to bag, quantity changes, remove items and subtotal calculation
- Colour swatch selection state
- Newsletter validation and feedback
- Keyboard focus, skip link, semantic landmarks and reduced-motion support

## Limitations

This is a front-end portfolio demo. Checkout/payment, stock management, user accounts and newsletter delivery are not connected. Images and fonts are loaded from external services, so internet access is needed for those assets. Footer and account links are placeholders.

## Test widths

320px, 375px, 768px, 1024px and 1440px. Also test keyboard-only navigation, 200% zoom, contrast, HTML validity and WAVE/axe. Automated scans alone do not establish WCAG conformance.
